## Dependency Graph

The logical flow of data and control for the modernization tracks:

    MeshTopology --> Mesh --> GlobalDofAssignment (GDAMinimumRule)
                                   |
                                   +--> BasisReconciliation --> LocalDofMapper
                                   |
                                   +--> GMGOperator --> Solution
                                                           |
                               CamelliaCellTools ----------+

- **MeshTopology** owns the combinatorial mesh: cells, entities, refinement tree, parent-child relationships. It is the lowest-level data structure and is consumed by nearly everything above it.
- **Mesh** is the high-level facade. It holds a MeshTopology and a GlobalDofAssignment and exposes the mesh API to formulations, solutions, and drivers.
- **GlobalDofAssignment** (abstract base) and its concrete subclass **GDAMinimumRule** use topology to determine DOF ownership, numbering, and constraints across nonconforming interfaces.
- **BasisReconciliation** resolves hanging-node constraints by constructing constraint matrices from coarse-to-fine basis relationships.
- **LocalDofMapper** maps element-local DOF indices to global DOF indices for assembly.
- **GMGOperator** uses the GDA and topology to construct prolongation/restriction operators between mesh levels for geometric multigrid.
- **Solution** uses the resulting global DOF maps to assemble and solve the linear system via Trilinos/Tpetra.
- **CamelliaCellTools** provides geometric mappings between reference and physical cell coordinates, called by both BasisCache and the geometry subsystem.
